# Asistora - Premium AI Chatbot Agency Website

## 🚀 Live Demo
Open in browser: `npx live-server .` (http://127.0.0.1:8080)

## 📋 Features
- 6 Professional pages (Home/About/Services/Pricing/Portfolio/Contact)
- Premium SaaS design (glassmorphism, animations, responsive)
- **Live AI Chatbot** (Groq-powered, site-aware)
- SEO optimized, PWA ready
- Zero bugs/overlaps

## 🔧 Chatbot Setup
1. Get Groq API key: https://console.groq.com/keys
2. Edit `js/chatbot.js` line 2: `const GROQ_API_KEY = 'your-key-here';`
3. Reload page → Click 💬 → Test!
